# 🚀 Run and Deploy

This project contains everything you need to run the application locally or deploy it to your preferred hosting platform.

## 📦 Prerequisites

- Node.js (v18 or later)
- npm

## ▶️ Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create a `.env.local` file and add your environment variables.

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```
   http://localhost:3000
   ```

## 🏗️ Build for Production

```bash
npm run build
```

## 🚀 Start Production Server

```bash
npm start
```
